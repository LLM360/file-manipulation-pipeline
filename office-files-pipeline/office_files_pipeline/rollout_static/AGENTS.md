# REQUIRED

- **Final deliverables MUST land in `./deliveries/`.** This directory is pre-created and is the *only* path where results belong. Anything you save outside `./deliveries/` is discarded. Multi-file deliverables stay together inside it.

- **ONLY After finishing your work, create file `.done` in your working directory**

- **Use the machine fully.** This is your sandbox: install whatever you need (`apt-get`, `pip`, `uv`, `cargo`, `npm`), Side effects on the host evaporate when you exit; don't hold back. `uv` is faster for python package management.

- **Directory Layout Check** After you return, these checks are enforced, if these don't pass your work won't count:
```

./
├── AGENTS.md
├── .done                 # <-- must exist; only create AFTER you have finished your work
├── reference_files/
└── deliveries/           # <-- your work! MUST NOT BE EMPTY

```
